# Chanda Manoj — Portfolio Website

A responsive, animated portfolio built with **Next.js 14**, **TypeScript**, **Tailwind CSS** and **Framer Motion**.

## Included sections
- Animated hero and navigation
- About
- Technical skills
- Three résumé projects
- IBM Data Analyst internship
- Education and certifications
- Contact details and LinkedIn link

## Run locally

1. Install Node.js 18.17 or newer.
2. Extract this ZIP and open the project folder in VS Code.
3. Open a terminal in the project folder and run:

```bash
npm install
npm run dev
```

4. Visit http://localhost:3000

To create a production build:

```bash
npm run build
npm start
```

## Before publishing

- Confirm the phone number, email and LinkedIn URL. The portfolio currently uses the public profile URL listed in your résumé: https://www.linkedin.com/in/chanda-manoj.
- Replace `https://example.com` in `app/layout.tsx` with your deployed website URL.
- Add GitHub repository/demo links and project screenshots only when you have verified public links/assets.
- If you prefer not to publish your phone number, remove the phone contact row from `app/page.tsx`.
- Deploy by importing the project into Vercel. Select the default Next.js build settings.
